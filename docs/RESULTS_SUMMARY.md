## 3. 分かったこと

1. **「下がったら買う」ルールだけでは優位性がない。** 候補全体の平均（+1.0〜1.7%）は、相場全体の急落日に候補が大量に出て一斉に反発したことによる見かけの数字。普段の日の候補の期待値はほぼ0。
2. **相場全体の下落に巻き込まれた銘柄は反発しやすい。** その日に価格条件を満たす銘柄の割合が47%超の日：日ごとの平均 +5.2%（開発）／+8.8%（評価）。13%以下の普段の日：−0.9%／−0.8%。両期間で一貫した唯一の強い効果。
3. **急落リスクを下げる特徴**：値動きが小さい、PBRが高すぎない、時価総額が大きい、黒字が続き財務が健全で配当がある。いずれもリスク（−10%以上の急落率）は下げるが、リターンはほとんど上げない。
4. **成績は「どの会社を対象にするか」に強く依存する。** 旧研究の8銘柄では同じルールで両期間プラス。ただし8銘柄は後知恵で選ばれた可能性がある。8銘柄の共通点（会社の質）を条件化したv4は、8銘柄以外でもリスク低減効果を確認（事前に決めた基準で合格）。
5. **Chronos-2（C0）は一貫した追加価値を示さなかった。** 急落率を2〜5ポイント下げる程度。モデル公開（2025-10、版の更新2026-06）以前の期間は学習データの影響も否定できない。
6. **ゴールデンクロス＋RSI（利確+5%／損切り−3%）は予測力なし。** 勝率39%で損益分岐とほぼ同じ。手数料の分だけ損失。同じ日に利確・損切りの両方に届いた取引は0.5%で、日足で判断して問題ない。
7. **インデックスの押し目買いは定額購入に負ける。** 反発効果はあるが、待っている間の上昇を逃す損失のほうが大きい。
8. **いずれの個別株戦略も、リターンでTOPIXの保有に大きく負けた。** 最大DDで勝つ期間はあるが、全期間では同程度。

## 4. 結論

試した中で最も良かったのは、**インデックスをタイミングを気にせず定期的に買い続ける**方法。

## 5. 注意点・限界

- 評価期間は、v3の特徴（相場条件など）を決める段階で参照済み。v3・v4qmの評価期間の成績は割り引いて見る必要がある。v4の質の条件だけは評価期間を事前に固定して1回のみ検証。
- 検証期間は日本株の上昇局面（TOPIX約2.8倍）。長い下落・横ばい相場での結果は不明。
- 個別株の収益は配当を含まない価格リターン。TOPIXも価格指数（実際のETFでは年2%前後の配当が加わる）。
- 2018年10月以前は単元株数が取れず100株単位と仮定。スリッページは手数料以外考慮していない。
- AI審査（P4）は未実施。個別に下げた銘柄の悪材料をAIが見抜けるかは未検証。
